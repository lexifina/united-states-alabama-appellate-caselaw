# S.L.P. v. D.A.P.

## Majority (ROBERTSON, Presiding Judge.)

On Application for Rehearing
ROBERTSON, Presiding Judge.
On May 7, 1999, this court affirmed the judgment in this case, without an opinion. — So.2d - (Ala.Civ.App.1999) (table). The appellant has applied for a rehearing; the application is overruled.
The appellant’s request for an attorney fee on application for rehearing is denied.
APPLICATION OVERRULED.
YATES, MONROE, and THOMPSON, JJ., concur.
CRAWLEY, J., concurs specially.

## Concurrence (CRAWLEY, Judge,)

CRAWLEY, Judge,
concurring specially.
Based on the authority of Hooten v. Hooten, [Ms. 2980190, July 16, 1999] — So.2d -(Aa.Civ.App.1999), I concur in the decision to overrule the wife’s application for rehearing and to deny her request for an attorney fee.
