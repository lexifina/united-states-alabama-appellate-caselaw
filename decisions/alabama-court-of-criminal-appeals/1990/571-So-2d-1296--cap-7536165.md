# Martin v. State

## Majority (BOWEN, Judge.)

ON RETURN TO REMAND
BOWEN, Judge.
On remand, the circuit court entered the following order: “Motion granted & Petition granted & disciplinary ruling set aside and ordered expunged from prison record.”
This action of the trial court renders this appeal moot. Therefore, this appeal is dismissed.
OPINION EXTENDED; APPEAL DISMISSED.
All Judges concur.
