# Steele v. State

## Majority (TAYLOR, Judge.)

TAYLOR, Judge.
Because of the Supreme Court’s reversal of this court’s ruling in Dison v. State, 469 So.2d 661 (Ala.Cr.App.), reversed, 469 So.2d 662 (Ala.1984), we must reverse the conviction in this case.
REVERSED AND REMANDED.
All the Judges concur.
