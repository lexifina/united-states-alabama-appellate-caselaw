# Matkins v. State

## Majority (McMILLAN, Judge.)

McMILLAN, Judge.
The appellant has failed to file a brief in this court. The appellee has moved for dismissal of the appeal pursuant to Rule 31(c), Alabama Rules of Appellate Procedure. Therefore this case is due to be dismissed pursuant to Rule 2(a)(2)(A), Alabama Rules of Appellate Procedure. See also Johnson v. State, 500 So.2d 494 (Ala.Cr.App.1986).
APPEAL DISMISSED.
All the Judges concur.
