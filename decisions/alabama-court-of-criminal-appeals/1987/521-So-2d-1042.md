# State v. Fields

## Majority (BOWEN, Presiding Judge.)

BOWEN, Presiding Judge.
This is an appeal by the state from an order of the circuit court declaring Alabama Code § 13A-10-31 (escape in the first degree) unconstitutional as applied to the accused and dismissing the indictment against Jimmy H. Fields. The judgment of the circuit court is reversed on authority of Webb v. State, 519 So.2d 1389 (Ala.Cr.App.1987).
REVERSED AND REMANDED.
All Judges concur.
