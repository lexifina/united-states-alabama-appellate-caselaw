# Anderson v. State

## Majority (PER CURIAM.)

PER CURIAM.
On April 8, 1983, the Supreme Court of Alabama, Anderson v. State, 434 So.2d 737, directed this court to remand this cause for a sentencing hearing with counsel present.
This cause is herewith remanded to the Circuit Court of Dallas County for a sentencing hearing as herein directed.
REMANDED WITH DIRECTIONS.
All the Judges concur.
