# State v. Wakefield

## Majority (PER CURIAM.)

PER CURIAM.
PETITION GRANTED. ORDER ISSUED FOR TRIAL COURT TO VACATE AND SET ASIDE THE SENTENCE OF 45 YEARS’ IMPRISONMENT; AND FURTHER THAT THE TRIAL COURT IS ORDERED TO SET SENTENCE AT 10 YEARS’ IMPRISONMENT IN ACCORDANCE WITH ALABAMA CODE 1975, SECTION 13A-5-6(a)(5).
All the Judges concur.
