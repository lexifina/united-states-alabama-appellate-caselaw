# Wade v. State

## Majority (BOWEN, Judge.)

ON RETURN TO REMAND
BOWEN, Judge.
On remand, the trial court dismissed cases CC-88-2140, -2141, and -2142. In CC-88-2139, the trial court sentenced the appellant to life imprisonment as a habitual felony offender with four prior felony convictions. This fully complies with the order of this Court, 581 So.2d 1255 on original submission.
The appellant’s conviction for conspiracy to commit robbery in the first degree in case CC-88-2139 is affirmed.
OPINION EXTENDED; AFFIRMED.
All Judges concur.
