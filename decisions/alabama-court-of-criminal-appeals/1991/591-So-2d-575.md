# Hugley v. State

## Majority (BOWEN, Judge.)

ON RETURN TO REMAND
BOWEN, Judge.
On remand, the trial court sentenced the appellant to 18 years’ imprisonment. This is a proper sentence in this case because the State did not give the required notice of the prior felony convictions.
The judgment of the circuit court is affirmed.
OPINION EXTENDED; AFFIRMED.
All Judges concur.
